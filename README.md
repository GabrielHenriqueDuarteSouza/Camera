# CamPro

Câmera própria (Camera2) para Android 11+ (feita para o Poco X7 Pro).

## Como compilar no GitHub
1. Crie um repositório e envie TODO o conteúdo desta pasta, incluindo a pasta oculta `.github/workflows/build.yml`.
2. Aba **Actions** > **Build APK** > se não iniciar sozinho, clique em **Run workflow**.
3. Quando terminar, abra a execução e baixe o artefato **CamPro-apk** (zip com o `app-debug.apk`).
4. Instale o APK (permita "instalar apps desconhecidos") e conceda a permissão de câmera.

## Primeiro uso
Toque em **Info** e use **Copiar**: o relatório mostra quais câmeras, resoluções, RAW e controles manuais o seu aparelho realmente libera para apps de terceiros.

## Recursos
- Troca de câmera (inclui lentes físicas, se o sistema liberar)
- Resolução do JPEG, JPEG ou JPEG+RAW (DNG), JPEG em qualidade 100
- Exposição manual (ISO + obturador), foco manual, balanço de branco, EV, zoom (slider ou pinça)
- Proc.: Mínimo (pede redução de ruído mínima e nitidez desligada; o efeito depende do aparelho)
- Fotos em Pictures/CamPro
